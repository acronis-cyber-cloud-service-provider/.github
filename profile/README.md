## Troubleshooting Common Issues

Install issues? Confirm outbound access to service endpoints and that the partner account is active.  
Performance problems? Check tenant quotas and policy assignment before investigating agent-side errors.  
License/activation? Reissue the agent registration token if a machine fails to appear in the console.  
Compatibility? Align agent and console versions during upgrades to avoid unsupported combinations.  
Update failures? Review the central job log first, since it often names the failing stage directly.
